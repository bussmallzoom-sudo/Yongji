# 永吉床墊網站設計預覽 V1

這一版結合討論稿的十種版型、原站品牌語氣與提供的四組參考。共輸出 15 個可導覽頁面：首頁、選床指南、床墊一覽、三款商品、認識闆娘、門市試躺、知識列表、四篇知識文章、售後問答及隱私說明。

## 開啟方式

直接開啟 `portable/index.html`。此資料夾的頁面採相對連結，無須安裝套件。圖片與字型目前使用網路資源，需要連線。圖片為原站 AI 示意，保留其性質標示。

原始碼位於此目錄。安裝 Node.js 後，可執行 `node build.mjs` 產生網站、`node check.mjs` 檢查頁面、`node serve.mjs` 啟動本機預覽。這一版不需要第三方 JavaScript 套件。

## 已實作

- 十種版型與十五個獨立網址、首頁三種需求入口。
- 商品與指南頁內導覽、款式比較表、相關商品與文章導流。
- 手機選單、固定聯絡列、可展開 FAQ。
- 詢問內容視窗：依商品帶入名稱，可修改、複製文字；未假冒送出或預約成功。
- 明確標示未確認的商品規格、門市及 LINE 資料，未虛構售價、人物經歷、評價、保固或服務。
- 桌機與手機 CSS、鍵盤焦點、略過導覽、原生對話框及減少動態偏好。

## 第二步：WordPress 轉版規劃

目前為靜態前端，尚非可安裝的 WordPress 主題。第二步將共用頁首、頁尾、字體與版面拆為主題樣式及可編輯區塊。商品資料型別建議放在配套外掛，以免換主題時資料消失。

| 內容 | 後台維護方式 | 建議欄位 |
| --- | --- | --- |
| 首頁 | WordPress 區塊編輯器與區塊樣板 | 主標、內文、桌機／手機圖片、精選商品與連結 |
| 商品 | 自訂商品內容類型 | 名稱、睡感定位、適合需求、圖集、材質結構、尺寸價格、售後、展示狀態 |
| 選床知識 | 原生文章與分類 | 標題、摘要、內文、特色圖片、分類、相關商品 |
| 闆娘介紹 | 可編輯頁面 | 人物介紹、照片、經確認原話與授權案例 |
| 門市 | 可編輯頁面與共用設定 | 店名、地址、營業時間、電話、LINE、交通、停車、展示與試躺安排 |
| FAQ 與政策 | 區塊樣板／頁面 | 問答、配送保固、付款及隱私內容 |

優先採原生區塊與可重複樣板，避免要求業主修改 HTML。商品圖與價目可分欄維護；首頁精選可選取已有商品，降低重複輸入。轉版後須在 WordPress 實際測試新增、修改、上傳圖片、手機顯示、權限與備份。
