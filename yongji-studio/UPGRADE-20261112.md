# 永吉網站整體升級：實作對照

依據《永吉床墊網站架構與設計討論稿 V2》，保留五項主選單、十種頁面／版型與十五個實際頁面；此輪為前端整理，不是 WordPress 主題交付。

## 首頁八段對照

| 原稿順序 | 實作區域 | 調整方式 |
| --- | --- | --- |
| 品牌主張與真實影像 | brand | 一句主標、一句品牌說明、一個主要入口；現有圖片仍標示 AI 示意，真實影像待提供 |
| 三個需求入口 | entrances | 幫我選床、看床墊、到店試躺，三個明確入口 |
| 闆娘怎麼協助選床 | method | 圖片搭配聊感受、選方向、親自試三個簡短步驟 |
| 精選款式與差異 | products | 三款商品統一圖片比例；詳細規格與差異在商品及比較內頁呈現 |
| 真實服務案例 | cases | 保留案例位置；沒有授權案例時清楚說明待補，不虛構見證 |
| 試躺流程及門市 | visit | 圖文說明與門市入口；完整流程、交通與到店資訊留在內頁 |
| 常見問題 | faq | 首頁三題原生展開問答，完整內容在 FAQ 頁 |
| 最後詢問與預約入口 | contact | 短句加諮詢入口；手機仍可進入到店頁 |

## UI 與內容規則

- 白底與極淡紙紋；保留綠色品牌和操作重點。
- 一套主動使用的 site.css，替換前幾輪的多份疊加樣式。
- 內文 16–17px、桌機區塊標題 29–38px，採正常與中等字重。
- 同類商品採一致圖片比例；減少英文小標、重複文案、編號、框線及多重按鈕。
- 保留五項導覽及完整內頁路徑，不將十種版型誤當成十個網址。
- 案例、售價、材質、電話、LINE、地址等未確認資料不自行補造。

## 第二階段 WordPress

維持既有 README 所列資料分工：可編輯首頁樣板、商品內容類型、原生文章、門市資訊及 FAQ／政策。商品內容與主題外觀分離，讓換主題時商品資料仍保留。此輪未啟動 WordPress 安裝或主題轉換。

## 本機使用

目錄最外層 index.html 連至 portable/index.html。dist 為 HTTP 發布版本，portable 為相對連結版本；同步使用 sync-portable.ps1。圖片與字型目前仍透過網路載入。
